# POL-SEC-2026-004 不正取引調査基準（PoC 初期ドラフト）

管轄: 金融不正分析室 / Trust & Safety / SecOps
関連: SOP-MLOPS-2026-002、PCI-DSS 要件 10/12

## 第1条 目的

日次バッチで記録された異常スコア付きトランザクションを、人手レビュー前に
優先度付けし、遮断・追加認証・監視の是正案を起案する。

## 第2条 即時監視（Priority-1）

次をすべて満たす取引は即時監視対象とする。

- `fraud_probability` >= 0.85
- `Amount` >= 200 USD
- 同一疑似日 `Date` における高額連続、または Hour が深夜帯（0-5）

Priority-1 は自動遮断 SQL の起案対象。本番適用は人間の承認後とする（本 PoC は提案まで）。

## 第3条 エスカレーション

- PSI >= 0.25: 自動遮断の一部停止を検討し、SecOps リードへ即時報告。
- 日次 PR-AUC < 0.80: モデル再学習パイプラインを起動する。
- 監査変数（V14, V17, V12）が SHAP 上位5から外れた場合、本規程第7条の改定案を起票する。

## 第4条 誤遮断コスト

- FN（見逃し）: 取引額全額 + チャージバック $15 + PCI 制裁係数
- FP（誤遮断）: 顧客離脱損失 + 手動審査 約 $5
- 閾値はコスト曲線 `ulb_fraud_detection_cost_curve` の最小点を優先する。

## 第5条 証拠

調査レポートには (1) 抽出 SQL (2) 件数 (3) KS/IV/Cliff (4) 規程条項番号 を必ず残す。
Zスコア差のみで遮断してはならない。

## 第7条 重要監視変数マトリクス

| 変数 | 理由 |
| --- | --- |
| V14 | 歴史的に不正クラスとの分離が安定 |
| V17 | ブーステッド木の Gain 上位に頻出 |
| V12 | 局所 SHAP で高額不正の寄与が観測される |
